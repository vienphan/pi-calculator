# 🧮 Pi Visualizer Lab

An interactive STEM web app that shows how π is approximated from a unit circle using equal angle divisions.

### ✨ Features
- **Slider:** Adjust α (1°–60°)
- **Auto Run:** Animation showing π convergence
- **Two dynamic charts:**  
  - π vs. α (with dashed true π line)  
  - Error (%) vs. α (filled red area)
- **Unit circle animation** for geometric intuition

### 🧠 Formula
\[
π ≈ m × sin(α), \text{ where } m = \frac{180}{α}
\]
